配電線 電圧見える化

6.6kV 放射状配電線 / LRT・SVR タップ整定 / 前進後退法潮流計算
計算の前提と式（必ずお読みください）
  • 3相平衡・単線表現。負荷は定電力、太陽光・蓄電池・データセンターも定電力出力（消費）として扱います。
  • 画面に出す電圧はすべて線間電圧（公称 6,600V）。内部計算は相電圧 V相 = V線間/√3 の複素数で行い、相あたり電力は 3相電力÷3 を使います。R・X は 1相あたりの Ω です。
  • 符号：負荷は消費が正。太陽光は発電（注入）。蓄電池 P は放電（注入）が正・充電が負、Q は注入（進み）が正。太陽光の力率が 1 未満のときは、無効電力を吸収（電圧上昇を抑える側）とします。
  • LRT 一次側は一定電圧。上位系統・LRT・SVR のインピーダンスは第1段階では無視（短絡容量・X/R は第2段階の事故計算用の入力欄のみ）。LRT・SVR は理想変圧器：比 a = 1 + n × (1段の変化率)、出力電圧 = a × 入力電圧、入力側電流 = a × 出力側電流。
  • SVR は「節点 k の下流側（区間 k+1 の入口）」に置きます。節点 k の負荷は SVR の上流側につながります。
  • 潮流計算（前進後退法）：後退で Ik = conj(Sk/Vk) を末端から足し上げ、前進で Vk+1 = ak·Vk − Zk+1·Ik+1。全節点の |ΔV| < 1e-9 pu で収束、最大 100 回。
LDC 制御点電圧（相・複素）: V̇c = V̇out − (Rc + jXc) · İ 表示・判定は線間: Vc = √3 · |V̇c| （LDC 切のときは Vc = √3·|V̇out|） 近似式（参考）: ΔVc ≒ √3 · I · (Rc·cosφ + Xc·sinφ)
  • タップ整定（時間変化は扱わない静的計算）：潮流計算 → 上流（LRT → 節点順の SVR）から順に自動モードの機器を調べ、最初に見つかった「|Vc − 目標| > 不感帯」の機器を 1段だけ動かす → 繰り返す。どの機器も動かなくなったら整定。同じタップの組み合わせが再び現れたら「ハンチングの可能性」として止めます。
  • LDC は機器を通る電流から線路の電圧降下を推定します。太陽光の逆潮流で電流が減る（逆向きになる）と降下を過小に見積もり、送り出し電圧を下げます。
  • 電圧上下限（初期 6,300〜6,900V）は高圧側の目安としてのダミー値です根拠は要確認
  • LRT・SVR・線路・機器の初期値はすべてダミーです実機の値は要確認

ダミー値の決め方（LRT の LDC と目標電圧、SVR の目標電圧）

  • 対象とする「初期状態」：太陽光 0〜100%（5% 刻み）× データセンター 接続／離脱のすべてのケース。
  • LRT の LDC は SVR の入口（節点5）の電圧を守る（SVR より下流は SVR が受け持つ）。
  • 補償インピーダンスは、重負荷（太陽光0%・DC接続）のときに、LDC の推定降下 (Rc·P₀ + Xc·Q₀)/V と、母線〜節点5 の実際の降下 Σ(Rk·Pk + Xk·Qk)/V が一致するように決める（Pk, Qk は区間 k の通過電力）。
Rc = Σ(k=1..5) R_k·P_k / P₀ = 0.408 Ω → 0.40 Ω （参考：線路そのものは R = 0.456 Ω） Xc = Σ(k=1..5) X_k·Q_k / Q₀ = 0.923 Ω → 0.90 Ω （参考：線路そのものは X = 1.140 Ω） 重負荷 P₀ = 4,065 kW, Q₀ = 1,567 kvar（V = 6,600 V のとき） → ΔV_LDC = (0.40×4,065k + 0.90×1,567k)/6,600 ≒ 460 V（実際の降下 480 V） タップが上がり送出が約 6,765 V になると、P₀・Q₀ と V が変わり ΔV_LDC ≒ 425 V、実際 460 V（推定 − 実際 = −35 V） 整定後 Vc ∈ [T−DB, T+DB]、送出 Vs = Vc + ΔV_LDC、節点5 V₅ ≒ Vc + (推定 − 実際) 上限: T + DB + ΔV_LDC,max ≤ 6,900 → T ≤ 6,900 − 50 − 425 = 6,425 下限: T − DB − 35 ≥ 6,300 → T ≥ 6,300 + 50 + 35 = 6,385 ハンチングしない: 2·DB > 1段 = 6,600 × 1.25% = 82.5 V → DB = ±50 V 送出電圧はタップで 6,600×(1 + n×1.25%) のとびとびの値しか取れないため、 6,385〜6,425 V の中で全ケースを計算し、上下の余裕が釣り合う値を選んだ → LRT: T = 6,420 V, DB = ±50 V（全42ケースで 下限まで 54 V、上限まで 53 V の余裕） SVR（節点5 の下流）: 下流での最大降下 215 V、最大上昇 111 V T − DB − 215 ≥ 6,300 かつ T + DB + 111 ≤ 6,900 → SVR: T = 6,650 V, DB = ±50 V
  • T の取りうる幅が 40 V しかないのは、母線〜節点5 の降下（重負荷で約 460〜480 V）が許容幅 600 V の大半を使うためです。
  • LDC 切で送出電圧を固定する場合、節点5 までの降下は 14〜480 V と変わるため、全ケースで上下限に収まる送出電圧の幅は 600 − 466 − 2·DB ≒ 14 V しか残らず、実際上は成り立ちません。比較グラフの LDC 切（目標 6,800 V）で重負荷のときに逸脱が出るのはこのためで、LDC が必要な理由です。
計算のしくみ（初心者向け・5ステップ）
  1. 潮流計算：各節点の負荷・発電から電流を求め、線路の抵抗・リアクタンスで電圧がどれだけ下がるかを計算します。電圧が変わると電流も変わるので、答えが動かなくなるまで繰り返します（前進後退法）。
  2. 制御点の電圧 Vc：LRT・SVR が「見張る」電圧です。LDC 切なら機器の出口の電圧そのもの。LDC 入なら、出口の電圧から「この先の線路で下がるはずの分」を引いた、少し先の地点の推定電圧です。
  3. タップの判定：Vc が「目標 − 不感帯」より低ければ 1段上げ、「目標 + 不感帯」より高ければ 1段下げ、その間（帯の中）なら動きません。
  4. 1台・1段ずつ：上流（LRT → 節点順の SVR）から見て、最初に帯の外にある 1台だけを 1段動かし、ステップ1 に戻ります。全台が帯の中に入れば「整定」。同じタップの組み合わせが 2度目に出たら、行ったり来たりしているので「ハンチングの可能性」として止めます。
  5. 表示：整定したタップで計算した電圧を、プロファイル・表・タイルに出します。

不感帯（DB）とは

「目標 ± DB の帯の中なら動かない」という遊びの幅です。1段動くと電圧は約「基準電圧 × 1段の変化率」だけ跳ぶので、帯の幅（2 × DB）が 1段の跳びより狭いと、どのタップでも帯に入れず、上げ下げを繰り返します（ハンチング）。

操作の順番で結果が変わる理由

帯の中ならどのタップでも止まるので、止まってよいタップが 2つ以上あることがあります。どれに止まるかは、出発点（直前のタップ）と、どの機器が先に動いたかで決まります。たとえば上流の LRT が先に動くと、下流全体の電圧が変わり、SVR が動く必要がなくなることがあります。実機でも同じことが起き、操作の履歴で整定位置が変わります（ヒステリシス）。このアプリは「上流を先に動かす」順に固定しています。
